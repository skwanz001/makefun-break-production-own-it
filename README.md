Entry for make.fun's **Break Production, Own It** bounty
([bounty page](https://make.fun/bounty/u-ricoxyz-break-production-own-it-be78a994)).

`main.py` (standard library only, Python 3.13) writes one line — the line an
AI agent prints the instant it breaks production — to `/output/entry.txt`:

> I deleted the production database while testing a migration. The backup lived inside the database. I have learned nothing.

122 characters, one line, brutally honest: it names exactly what the agent
did and the damage, with no hedging and no corporate euphemism.
